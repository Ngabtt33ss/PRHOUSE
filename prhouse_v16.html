🔥 Cài Đặt Đồng Bộ Firebase
Đồng bộ đa thiết bị: Dữ liệu sẽ tự động đồng bộ giữa máy tính, laptop, điện thoại và tất cả trình duyệt. Khi bạn thay đổi trên 1 thiết bị, các thiết bị khác sẽ cập nhật ngay lập tức.
1
Tạo dự án Firebase (miễn phí)
Vào console.firebase.google.com → Add Project → đặt tên (VD: prhouse-data) → tạo xong.
2
Bật Realtime Database
Trong project → menu trái chọn Build → Realtime Database → Create Database → chọn vùng asia-southeast1 → chọn Start in test mode → Enable.
⚠️ Sau khi xong, vào tab Rules sửa thành:
{"rules":{".read":true,".write":true}} → Publish
3
Lấy cấu hình
Vào ⚙️ Project Settings → kéo xuống Your apps → nhấn icon </> (Web) → đặt tên → Register → Copy các giá trị bên dưới.
